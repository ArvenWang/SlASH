# Project Slash — Character Art Bible

文档版本：v1.4
状态：V5 视觉风格保留；正式生产输入升级为 V5R，供模型、材质、Rig、动画、武器和最终视觉验收共同使用。

## 0. V5R 正式生产修订（2026-08-12）

V5 的黑曜主角、朱红重装敌人、多面大切面和 Transit Cathedral 配色继续保留；本轮不重新发明视觉风格。V5R 修订的目标是把已认可风格转换成可生成、可清模、可绑骨、可动画、可替换的正式资产，并修复游戏内表现低于概念图的问题。

- `hero-turnaround-v5.png` 与 `enemy-turnaround-v5.png` 作为风格和角色身份参考；正式生成输入必须另行制作前/左/后/右四视图 A-Pose，身体不携带武器，并附材质分区、关节说明和独立武器图。
- 动作表沿用 v2 的方向语言，但必须升级为具有脚底接触、重心、主副手握点、刀尖轨迹和关键过渡的正式动作规格。
- 主角必须像一个连续、修长、可动画的人体，而不是由躯干筒、肢体棍和鞋块组装的模型；敌人必须是宽重的人体装甲轮廓，而不是玩具机器人。
- 多面几何来自经过控制的人体曲面和大切面，不来自减少到无法表达肩胛、骨盆、肘膝和足部结构的低面数。
- 主角身体与刀具必须分离生产。刀具总长从旧版约身高 93% 修订为身高 `58–66%`，首轮比较 `58% / 62% / 66%`；必须提供主/副握点、护手、刀根、刀尖和拖尾锚点。
- 该修订不改变 Gameplay 尺度：主角 `3.3m`、敌人 `3.157m`、两者 `+Z` 朝向；旧资产专属 Rig 不再视为不可改变项，正式模型必须使用可映射的标准语义骨架。

## 1. 共同视觉语法

- 角色是原创未来战斗者，不复刻任何现有游戏、影视或动漫角色。
- 风格是比例正确的低至中多边形切面造型：少量大平面、清晰转折、手工控制轮廓，不追求照片级皮肤或密集机械碎件。
- 角色必须首先服务高位远镜头：头、肩、腰、腿、武器和敌我阵营在约 64px 高度仍然可辨认。
- 材质以大块明暗和粗糙度差异建立层次；禁止用大量小贴花、随机发光线和紫色霓虹掩盖造型问题。
- 所有关节需要真实可动画，甲片不能在 Idle、Dash、Arrival、Locomotion 和 Death 中持续穿模。

## 2. 主角 / Cold Blade

锁定参考：

- `art/characters/concepts/hero-turnaround-v5.png`
- `art/characters/concepts/hero-action-sheet-v2.png`

造型：

- 成人、约 7.9 头身，细长、长腿、窄腰、紧凑肩线；气质是精准、克制、极快。
- 头盔为向前收束的黑曜石棱锥，唯一主识别点是断续式冷白横向多目视窗。
- 身体主体是连续的黑色人体大形，石墨甲只形成胸骨、外前臂、髋部和胫骨的少数大切面；不使用悬垂碎片、独立肩帽或装饰性小甲片。
- 正常状态仅允许视窗与刀身发出冷白/青白光；身体不再依靠多条发光饰线建立层次。
- 武器为明显短于身高、极薄、轻微弯曲的未来能量刀；使用克制的深色刀脊/刀身和从两面都能读出的单侧冷白能量刃，以明确真实开刃方向，并配极简深色柄和护手。禁止厚重黑芯、刃线细到不可读、观察方向一变就像刃口翻面、粗光棍或激光柱。

## 3. 敌人 / Vermilion Enforcer

锁定参考：

- `art/characters/concepts/enemy-turnaround-v5.png`
- `art/characters/concepts/enemy-action-cut-sheet-v2.png`

造型：

- 成人、约 7.4 头身；肩、胸、前臂和大腿宽重，腰部紧凑，视觉重量明显高于主角。
- 头盔为短促楔形，仅保留一条红橙传感器缝。
- 主识别块是单一、完整、非发光的朱红倒 V 胸甲与一块朱红左肩；删除散落红色小片和装饰性微型面板。
- 武器是短重实体切刀，黑色单体几何体＋细红橙热刃；禁止枪械和长柄武器。
- 颈、斜胸/腰、上臂和大腿必须预留模块化切割接缝，以支持延迟切口与少量明确的大块分离。

## 4. 动画身体语言

主角：Ready 中双脚落地、骨盆低、胸肩前压、刀柄真实进入掌心并贴近腰侧，不能读成跑步定格；Anticipation 通过进一步压低重心和拉出刀线实现，不增加逻辑延迟；Dash 是一条拉长的身体线；Arrival 有明确制动和 80–180ms 收刀恢复。Vector Focus 必须补齐 Activate、Selection Loop 和三段 Chain Slash，所有状态保持主手握点，双手动作还要保持副手握点。

敌人：Locomotion 由胸腔带动、步幅与速度匹配；总前倾必须读成冲跑而非爬行。至少四种姿态家族打散步相、肩线、躯干倾角和武器高度；攻击有近距离威胁姿态；被斩后先保持短暂惯性并亮起切缝，再按斩击方向分离和落地。

## 5. 正式模型精细度

- 主角 LOD0 目标 `8k–16k triangles`，敌人 LOD0 目标 `6k–12k triangles`；数量只用于阻止明显的粗模占位，不允许无意义细分凑数。合理偏离必须用连续轮廓和真实战场性能证明。
- 近景必须能看出锁骨/肩峰、胸腰收束、骨盆转折、肘膝方向、踝部和楔形足部；这些结构应由连续表面表达，不增加零碎装饰。
- 颈、肩、肘、腕、髋、膝、踝在 Ready、Dash、Recovery 和 Locomotion 中不得露出平端盖或形成悬浮间隙。
- 主角材料语义最多三类：近黑身体、石墨大面、冷白能量；敌人最多四类：近黑软层、炭灰甲、朱红识别块、红橙热源。
- 正式通过需要同时检查近景四视图、Rig 压力姿势、动作关键姿态和生产战场；任一层出现“积木、胶囊、玩具、断关节、站桩、刀光吞人”即退回。

## 6. 不可偏离项

- 不把主角改成宽肩通用科幻士兵；
- 不把敌人改成枪兵、警察、卡通机器人或巨型动力甲；
- 不使用传统武士盔甲、斗笠、鸟居、和服或符号拼贴替代原创设计；
- 不用整体缩放、瞬移和随机散架冒充动作与死亡；
- 不在未经记录的情况下改变锁定的敌我配色、武器长度或主要轮廓。
