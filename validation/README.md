规则：

- 只保存来自实际运行游戏、生产构建或正式测试的证据；
- 概念图不能充当实时画面证据；
- 每轮截图和报告必须标明版本、浏览器、分辨率、质量档和测试场景；
- 未完成的证据项保持缺失，不使用空文件或假数据冒充通过。
