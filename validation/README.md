# Project Slash Validation Evidence

本目录用于存放 `docs/ACCEPTANCE_STANDARD.md` 要求的真实验收证据。

规则：

- 只保存来自实际运行游戏、生产构建或正式测试的证据；
- 概念图不能充当实时画面证据；
- 每轮截图和报告必须标明版本、浏览器、分辨率、质量档和测试场景；
- 未完成的证据项保持缺失，不使用空文件或假数据冒充通过。

当前状态：验收框架与主要自动化证据已建立。大型截图、视频和性能记录保留在本地工作区，不进入 Git；仓库只跟踪本说明、`tools/` 中的可复用验证脚本以及精简许可证审计。
